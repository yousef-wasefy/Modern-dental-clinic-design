# DentaCare - Dental Clinic Landing Page

A responsive dental clinic landing page built with HTML, CSS, and JavaScript.

## Project Goal

This project is built as a portfolio project to demonstrate the ability to create a professional and responsive business landing page from a design reference.

## Technologies

* HTML5
* CSS3
* JavaScript

## Features

* Responsive layout
* Modern dental clinic design
* Mobile-friendly navigation
* Services section
* About section
* Contact section

## Status

Currently under development.
